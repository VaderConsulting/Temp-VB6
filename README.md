# Temp

Small VB6 scratch project (`Project1`) that walks folders, merges MSXML 4.0 documents/fragments, and can load scripts into `msscript.ocx` / Scripting Runtime helpers. Distinct from the later VS 2003 Temp repo. Open `Project1.vbp` in the VB6 IDE.

**Source last updated:** 2026-08-27 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** WinForms exe

## Solution structure

| Project | Language | Type | Purpose |
|---------|----------|------|---------|
| `Project1` (`Project1.vbp`) | VB6 | WinForms exe | Scratch XML merge / ScriptControl experiments |

## How to open

Open the `.vbp` in Visual Basic 6.0 IDE:
- `Project1.vbp`

## Requirements

- Visual Basic 6.0 IDE
- Registered OCX/DLL dependencies referenced by the `.vbp` (may need to be installed separately):
  - `msscript.ocx`
  - MSXML 4.0
